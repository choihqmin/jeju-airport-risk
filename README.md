# 제주공항 결항 위기 예보

제주공항의 내일 결항 위기(국내선 결항편 예약 인원 3,000명 이상, 제주도 체류객 대응 '주의' 단계 기준) 가능성을
전날 17시 30분까지 공개된 공공데이터만으로 예보하는 학생 분석 프로젝트의 공개 화면입니다.

- `index.html` 화면 (대응 실무자 / 여행객)
- `data/latest.json`, `data/history.json` 매일 17:45 갱신되는 예보 요약 (원자료·인증키는 올리지 않음)
- `data/reference.json` 과거 검증 결과에서 가져온 단계별 실제 빈도와 핵심 수치
- `tools/publish_site.mjs` 분석 PC에서 예보 요약을 만들어 올리는 스크립트

항공사·공항의 공식 안내를 대신하지 않습니다.
