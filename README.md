# 제주 표류 전망 (Jeju Pyoryu Outlook)

**하루 먼저 보는 제주 공항 결항 위기** · https://choihqmin.github.io/jeju-airport-risk/

다음 날 제주 공항에서 출발하는 국내선에 결항이 몰려 **결항편 승객(추정)이 3,000명 이상**이 될 위험을, 전날 17시 30분까지 공개된 공공데이터로 판단해 세 단계로 알리는 학생 분석 프로젝트의 공개 화면입니다. 3,000명은 「제주공항 체류객 지원 매뉴얼」의 '주의' 수치 조건을 따른 것입니다.

| 단계 | 뜻 |
|---|---|
| 보통 | 평소 수준 |
| 주의 가능성 | 대비 점검이 필요한 날 |
| 주의 높음 | 체류객 대응을 미리 준비할 날 (사전 등록한 경보 기준) |

- 매일 17시 35분에 모델 예측을 내고, 17시 45분에 항공기상청 예보관의 17시 제주공항 기상정보와 결합한 단계를 게시합니다.
- 화면은 대응 실무자용과 여행객용 두 가지입니다.
- 모델(지문 `53887ccced3d62b7`)과 단계 기준, 채점 방법은 첫 예보(2026-11-04) 전에 고정했습니다. 11월 5일 대상부터 다음 날 한국공항공사 운항 기록으로 채점해 화면의 '과거 적중 기록'에 그대로 쌓습니다.
- 쓰는 자료: 기상청 단기예보·기상특보·공항 관측(AMOS·METAR), 항공기상청 제주공항 기상정보, 한국공항공사 운항 실적, 편당 탑승객 통계.

## 저장소 구성
- `index.html`: 화면 (대응 실무자 / 여행객). `sw.js`·`manifest.webmanifest`·`icons/`는 홈 화면 추가용입니다.
- `data/latest.json`, `data/history.json`: 매일 17:45 갱신되는 예보 요약과 실시간 기록 (원자료·인증키는 올리지 않음)
- `data/reference.json`, `data/backtest_calendar.json`: 과거 검증 결과의 단계별 실제 빈도, 2025~2026년 달력
- `tools/publish_site.mjs`: 분석 PC에서 예보 요약을 만들어 올리는 스크립트

분석 코드·정리 자료·결과·사전 등록서는 2026 제주대학교 경영정보학과 빅데이터 분석 경진대회 보고서와 함께 재현 자료로 제출했습니다.

이 화면의 단계는 연구자가 낸 사전 전망이며, 공식 체류객 지원 단계 발령이나 항공사·공항의 공식 안내를 대신하지 않습니다. 실제 운항 여부는 항공사 앱과 한국공항공사 안내에서 확인하세요.
